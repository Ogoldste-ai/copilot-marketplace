# Review workflow

## Reviewer checklist

1. Confirm the trigger phrase is unique.
2. Confirm the scope is narrow.
3. Confirm the source file path exists.
4. Confirm the permissions match the request.
5. Confirm the wording is safe and clear.

## Decisions

- `approve` - ready to publish
- `request-changes` - needs revision
- `reject` - should not be published

## Notes

Keep review notes attached to the request so future changes can reuse the same history.
